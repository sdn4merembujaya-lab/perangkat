# Perangkat Ajar KM SD

Upload `index.html`, `perangkat-ajar.html`, `guru.json` ke repositori GitHub, lalu aktifkan
**Settings → Pages → Deploy from a branch → main / (root)**. Buka `https://USERNAME.github.io/NAMA-REPO/`.

Akun awal: `admin` / `admin123` dan `guru1` / `guru123` (kelas 4). Segera ganti kata sandi di menu **Akun Saya**.
Tambah guru lewat menu **Data Guru**, klik **Unduh guru.json**, lalu ganti file `guru.json` di repositori.

Catatan: login ini berjalan di browser (situs statis), jadi cocok untuk memisahkan data tiap guru, bukan untuk data rahasia.
